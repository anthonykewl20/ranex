**Status:** open

This change repairs the executable paths identified by the code audit:
admission retains record identity through qualification; task judge and
merge use the same full gate evaluator; history binds every durable
observation to an independently retained service-signed checkpoint;
legacy signature-only verdicts remain archival and cannot authorize current
acceptance. History bootstrap, migration and recovery are explicit operations.

Promotion validates complete finite numeric inputs before arithmetic. Batch
worktree ownership is exclusive, qualification attestation binds the actual
payload, unsupported DAG shapes refuse before allocation, and lifecycle
sessions retain reviewed manifest identities. GitHub delivery identities
include installation and repository.

Scanners retain structural failures, prune nested nonexecuting test bodies,
union baseline inventories and resolve every imported alias. Marker positions
handle Unicode. Delegated review retains canonical finding identity, category
and rule-default severity; every explicit review packet and coverage witness
is checked before acceptance. Reduction semantics are version-bound so older
signed summaries cannot silently satisfy the new contract.

Provisioning propagates extras to a fixed point, uses measured target tags
from installed packaging, and installs private copies of already verified
wheel bytes. Host reports retain bounded redacted log references and child
processes run from the governed checkout. Worker output cannot contaminate the
controller result channel. Diagnostic emission does not block full pipes.

Repair hooks retain selected gate and stable loop identity across commits;
wrapped suite commands are checked. Targeted reproduction replaces original
pytest collection operands, and JUnit receives exact observed pytest nodeids.
Benchmark empty inventories cannot verify; receipt heads and applied gold
patch provenance bind actual controls, and assignment-bearing commands share
execution semantics across arms.

Qualification evidence and limitations will be completed after the final
committed-tree suite, manifest freeze/load and independent review. AST assertion
census remains a structural heuristic. SARIF schema validation alone does not
prove all coordinate semantics or a delegated model's review effectiveness.

Independent review reproduced a task-merge history/CAS race (#196) and a
required-review downgrade (#197). Merge now holds the authenticated history
serialization boundary through its ref update. Antislop's explicit empty
coverage is a missing inventory, and concurrent repair hooks serialize their
miss budgets rather than losing increments. Invalid budget state refuses.

The pinned static and native build closures were remeasured from actual
compiler-opened inputs, independently rebuilt twice and matched byte for byte.
Public launcher build/install/qualify passed for this isolated candidate only;
newer user checkout changes have not been included or qualified.

The shared SARIF reader validates the core fields the gate interprets before
reduction. Mandatory delegated-review claims use a dedicated reporter binding
and reject absent or substituted packets. This is a bounded ingestion profile,
not a claim of complete SARIF conformance or model-review effectiveness.

Task-journal receipts preserve their separate authority under verdict v3:
they carry no repository-history checkpoint and cannot authorize a current
repository gate. Task landing still evaluates current gate evidence.
