# Ranex Documentation

Single entry point for everything under `docs/`. Nothing here is runtime-proven:
the architecture is accepted **on paper** (ADR-0003), and neither
`IMPLEMENTATION_START_READY` nor `PRODUCTION_READY` has been declared
(see ADR-0012).

## Start here

> ### 📍 [`architecture/MASTER_ARCHITECTURE_SPECIFICATION.md`](architecture/MASTER_ARCHITECTURE_SPECIFICATION.md)
>
> **The map.** The whole intended system, with every claim labelled
> `CONFIRMED` / `PROVISIONAL` / `UNRESOLVED` / `OUT-OF-SCOPE`. Read this before
> anything else. It is the only document that shows what is actually proven
> versus merely written down.

**AI agents:** read [`AGENTS.md`](../AGENTS.md) at the repository root first. It
states what you may and may not do, in under 100 lines.

## Read by task, not by role

**Do not read the corpus in order.** It exceeds ten million tokens and no task
needs it. Read the one document that matches what you are doing.

| Your task | Read this, and stop |
|---|---|
| Understand the system | The **Master Architecture Specification**, above |
| Decide whether something is settled | The MAS §9 decision index, then the specific ADR |
| See what is proposed but not decided | [`architecture/rfcs/README.md`](architecture/rfcs/README.md) — **no authority** |
| Continue an in-flight session | [`HANDOFF.md`](HANDOFF.md) |
| Check a specific rule, gate or ID | [`architecture/SDLC_CONTROL_CATALOG.md`](architecture/SDLC_CONTROL_CATALOG.md), [`architecture/SOURCE_OF_TRUTH.md`](architecture/SOURCE_OF_TRUTH.md) |
| Understand the SDLC process itself | [`architecture/CORE_SDLC_OPERATING_MODEL.md`](architecture/CORE_SDLC_OPERATING_MODEL.md) |
| Read the full target design | [`architecture/HERMES_GROUND_ZERO_FULL_SYSTEM_ARCHITECTURE.md`](architecture/HERMES_GROUND_ZERO_FULL_SYSTEM_ARCHITECTURE.md) — 4,198 lines; the MAS summarises it |
| Know what Hermes material is inherited, and whether Slice 1 is safe to build | [`foundation/slice-1-readiness-assessment.md`](foundation/slice-1-readiness-assessment.md) — start there; the other five foundation documents are its evidence |

The former "read these 14 documents in order" instruction in
[`architecture/README.md`](architecture/README.md) remains valid as a **complete
index**, but it is no longer the recommended entry path: reading 12,000 lines
before acting is the Big-Design-Up-Front habit this project is correcting.

## Owner reading path

You are not expected to read the architecture. Read the MAS §1 (what Ranex is
and what it owes you), §11.1 (unresolved risks), and §13 (what is being built
next). That is enough to make every decision currently waiting on you.

## Rules that keep this tree trustworthy

- **Generated:** everything under `architecture/assessments/` is regenerated by
  scripts; hand edits will be overwritten or fail validation.
- **Digest-bound:** the `.sha256` manifests under `architecture/reviews/artifacts/`
  freeze exact bytes and paths of many documents (including research files and
  `legal/licensing-manifest.json`). Renaming or moving a listed file breaks the
  evidence chain. `research/ranex-architecture-practice-application-profile.json`
  is additionally pinned by a hardcoded digest inside
  `scripts/architecture/validate_contracts.py`.
- **Historical:** a document dated 2026-07-27/28 that references the retired
  `RANEX_IMPLEMENTATION_GUIDE.md` is readable history under ADR-0002, never
  current instruction.
- **Local-only:** `research/books/` and `research/kimi-research/` are
  git-ignored consultation copies; their public representation is the digest
  manifests under `architecture/reviews/artifacts/`.
