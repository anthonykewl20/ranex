The problem it solved: “but the tests were green!”

The scariest failure in AI-assisted coding isn’t a crash — it’s a green checkmark on broken work. Here’s that exact scenario, built from our runs: a solved task where the agent then “cleans up” four inconvenient tests.

How it works — three moves, no magic

1
The checklist is frozen first
Before the agent touches anything, the owner commits the exact list of checks that will count as done. The goalposts are in the record book before the game starts — the agent cannot move them.
2
“Done” must arrive signed
A completion isn’t a sentence, it’s a signed test run: the exact commands, bound to the exact version of the code, with results that must match the frozen checklist. Faked or stale runs don’t count.
3
The record book is chained
Every decision is appended to a hash chain — each entry seals the previous one. Editing history leaves visible damage, and anyone can re-verify the whole chain in milliseconds.
